# Contribuir

Use Issues para discutir mudanças. Ao enviar um pull request, descreva o problema, comportamento esperado, testes e impacto nos dados. Execute `npm test` e `python scripts/build.py`. Use apenas fixtures sintéticas ou com licença adequada. Mudanças de metadados precisam de revisão explícita, histórico e reversão que preserve edições posteriores.
