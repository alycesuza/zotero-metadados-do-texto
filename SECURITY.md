# Segurança e privacidade

Não publique credenciais, PDFs particulares ou relatórios da sua biblioteca. Para relatar uma vulnerabilidade, use o contato do perfil do mantenedor e envie apenas os detalhes necessários, sem dados pessoais da biblioteca. Os plugins têm os privilégios de extensão do Zotero; revise o código e instale versões de fonte confiável.
